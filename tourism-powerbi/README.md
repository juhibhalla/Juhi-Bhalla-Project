# Tourism & Hospitality Industry Analysis – Power BI Report

An interactive Power BI report with four pages, one for each use case:

| Page | Use case |
|---|---|
| Market Analysis | Travel trends and popular destinations |
| Revenue Forecasting | Hotel occupancy and revenue patterns, with a 2025 seasonal-trend forecast |
| Hospitality Insights | Customer preferences and spending habits |
| Tourism Policy | GDP contribution, employment, eco-tourism, carbon and infrastructure |

## Contents

| Path | What it is |
|---|---|
| `PowerBI/Tourism_Analysis.pbip` | Power BI Project. Open it in Power BI Desktop. |
| `PowerBI/TourismTheme.json` | Report colour theme |
| `data/` | Source CSV |
| `Docs/Tourism_PowerBI_Report_Guide.docx` | Step-by-step build guide |
| `Video/Tourism_Report_Walkthrough.mp4` | Walkthrough video |
| `Report_Preview/Tourism_Report_Preview.html` | Interactive preview that runs in a browser |
| `tools/` | Scripts that generate the project, preview, video and guide |

## Open the report

1. Copy `data/Tourism_Hospitality_Industry_Analysis.csv` to `C:\PowerBI\`, or change the `CsvFilePath` parameter (Transform data > Edit parameters).
2. Open `PowerBI/Tourism_Analysis.pbip` in Power BI Desktop.
3. Click **Refresh**, then use **File > Save as** to save a `.pbix` file.
